# Imported Haiku themes

These theme definitions and available screenshots were imported from
[mmuman/HaikuThemes](https://github.com/mmuman/HaikuThemes) at commit
`d8a3a8de5487b4594997874d1262a0af8363653f`.

The upstream repository does not include an explicit licence file. Confirm
redistribution permission with the upstream maintainer before publishing a
release containing these resources.

Only themes whose definitions contain no ZETA references or `/boot/beos`
paths are included in the application. Historical ZETA/BeOS themes and large
third-party font, sound and wallpaper bundles are deliberately excluded.
